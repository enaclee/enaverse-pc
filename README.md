# enaverse PC

Автор **enaclee** · ID `com.enaclee.enaverse` · 1.0.0

Русскоязычная адаптивная локальная рабочая среда. Windows x64, Python 3.13, браузерный интерфейс на loopback. Это не Android APK и не торговый терминал с реальными ордерами.

## Скачать и запустить

1. Открыть [Actions](https://github.com/enaclee/enaverse-pc/actions), выбрать успешный запуск **Build enaverse Windows x64**.
2. В Artifacts скачать `enaverse-Windows-x64`, полностью распаковать ZIP.
3. Запустить `start.cmd`. Откроется локальный интерфейс; консоль содержит адрес сервера. Закрытие вкладки не останавливает процесс; для остановки закройте консоль или нажмите Ctrl+C.
4. Настройки → ENACORE → выбрать доверенный ZIP и ввести полученный отдельно SHA-256. Проверки архива и самотесты выполняются до переключения версии.
5. Нажать «Проверить здоровье», затем «Запустить аналитику». Прогнозы появляются только после получения достаточных свежих данных. Откат переключает версию, а не восстанавливает данные; резервная копия сохраняется.

## Реализовано

- Торговля: публичные REST-данные Bybit linear, стакан, закрытые свечи, рыночные и лимитные бумажные заявки, PnL, комиссии, приблизительная изолированная ликвидация.
- Боты: тестовые Grid, DCA, Breakout, Basis (long spot + short perpetual). Basis требует свежих котировок обоих рынков. Исполнение по лучшим ценам без моделирования глубинного проскальзывания.
- AI: локальные числовые сценарии и фактические ответы ENACORE. Дополнительно можно явно подключить Ollama, OpenAI или Gemini, указав доступное имя модели; внешний ключ хранится только в памяти. Модель получает только выбранный контекст запроса и поддерживает продолжение диалога. Оценка влияния новости появляется после запроса модели и помечается как AI-оценка, не факт.
- Новости: RSS Cointelegraph/CoinDesk, эвристические категории, поиск, закладки с сохранением материала.
- Настройки: две темы, плотность, валюта, таймфрейм, публичная сеть, сброс PAPER-портфеля, установка/откат ядра.

## Ограничения и безопасность

- Реальные ордера, ключи Bybit и авторизация торговли отсутствуют. PAPER-симуляция не моделирует биржевые маржинальные ступени, очереди исполнения, фандинг, все комиссии или рыночную глубину.
- Не путать бумажные стратегии приложения и прогнозы ENACORE. Ядро работает отдельным процессом; его автономный исследовательский контур не направляет торговые заявки в симулятор автоматически.
- Сервер доступен только на 127.0.0.1; сессионный токен требуется для API. Мобильная адаптация не означает удалённый доступ с телефона. Загружаемый ZIP выполняется с правами текущего пользователя. SHA-256 подтверждает целостность, не происхождение; проверяйте доверенный источник.
- Данные сохраняются в %LOCALAPPDATA%/enaverse. Смена сети требует отсутствия открытых позиций, заявок и ботов. Не запускайте одновременно два экземпляра.
- Обязательные зависимости ядра включены; расширенные ML/research пакеты не включены. Сетевые ограничения Bybit/RSS могут препятствовать получению данных, и интерфейс сообщает об отсутствии связи. USD/EUR/RUB — ориентировочный пересчёт через USD, без гарантии курса USDT.
- Plus Jakarta Sans используется для поддерживаемых символов, кириллица — системный fallback. JetBrains Mono — для чисел.

## Разработка

Python 3.13: `python -m pip install numpy==2.3.5 websocket-client==1.9.0 "psutil>=5.9,<8"`. Запуск: `python app.py`. Проверки: `python -m unittest discover -s tests -v`, `node --check web/app.js`. GitHub Actions собирает переносимый Windows-пакет с собственной средой и лицензиями шрифтов. Сам архив ENACORE в репозитории отсутствует.
